# 📰 Fake News Detector

A Fake News Detection Web Application built using Python, Flask, Machine Learning and NLP.

## 🚀 Features

- Detects Fake or Real News
- NLP Text Preprocessing
- Machine Learning Prediction
- Confidence Score
- Model Accuracy Display
- Prediction History
- Clear History Option
- Dark Mode
- PDF Prediction Report
- Date and Time in Report

## 🛠 Technologies Used

- Python
- Flask
- Scikit-learn
- NLP
- NLTK
- Pandas
- HTML
- CSS
- JavaScript
- ReportLab
